# Screenshot Checklist

This checklist documents the screenshot capture process for the README.

## Capture Steps

### 1. Landing Page
- Start the application: cd frontend && npm run dev
- Wait for the page to load
- Take screenshot of the landing page showing the interview start CTA
- File name: landing-page.png

### 2. Interview Question
- Progress through the interview by answering one question
- For example: select a budget option and a use case
- Take screenshot showing the question and current progress
- File name: interview-question.png

### 3. Results with Breakdown
- Complete the interview and view the results
- Ensure the breakdown section is visible with per-factor scores
- Take screenshot showing the results cards with breakdown
- File name: results-with-breakdown.png

### 4. Comparison View
- Select up to 3 recommendations for comparison
- Take screenshot showing the side-by-side comparison table
- File name: comparison-view.png

### 5. Share Link Reload
- Click Copy results link
- Paste the link in a new browser tab
- Verify the same results render
- Take screenshot showing the share link and reloaded results
- File name: share-link-reload.png

## Verification
- All screenshots must be unedited screenshots from the running application
- No mockups, no images from different apps
- File names must match the listed names
- If any screenshot cannot be captured, document the issue in this checklist rather than using a different image
